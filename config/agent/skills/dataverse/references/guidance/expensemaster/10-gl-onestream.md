## GL & OneStream

Use this section for variance, load rate, spend by department/vendor/account/period/geo, rankings, YoY, and headcount (see [Question coverage](#question-coverage-which-tables-to-use)). Base tables: GL_SUB_LEDGER_AGGREGATE, ONESTREAM_FINANCIAL_AGGREGATE, ONESTREAM_HEADCOUNT_AGGREGATE. If using `EXPENSEMASTER_DB.TEST_MARTS`, use `TEST_` prefixed table names (for example, `TEST_GL_SUB_LEDGER_AGGREGATE`, `TEST_ONESTREAM_FINANCIAL_AGGREGATE`, `TEST_ONESTREAM_HEADCOUNT_AGGREGATE`). For critical rules see [Critical rules](#-critical-rules) → **GL & OneStream**.
