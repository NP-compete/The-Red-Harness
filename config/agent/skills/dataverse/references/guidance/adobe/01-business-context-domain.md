## Business Context & Domain

**Adobe** (Adobe Analytics) provides Red Hat's web analytics and digital marketing measurement data. The `adobe_mrktng` mart exposes hit-level Adobe Analytics data for marketing analytics, attribution, and campaign performance.

### Key Business Value

- **Marketing Touchpoints**: Hit-level web analytics (page views, events, visits)
- **Campaign Attribution**: Track campaign performance via `post_campaign`, `post_channel`
- **Visitor Analytics**: Session/visit tracking via `mcvisid`, `visit_num`, `adobe_session_id`
- **Geographic & Device**: Geo (country, region, city), browser, OS, connection type
