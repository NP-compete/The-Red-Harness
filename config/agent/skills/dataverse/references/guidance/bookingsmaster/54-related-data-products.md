## 🔗 Related Data Products

**When to Use Other Data Products**:

| Need | Use This Data Product | Why |
|------|----------------------|-----|
| Revenue recognition, GL data | **RevenueMaster** | Bookingsmaster only has bookings/ARR |
| Targets, MJ, forecasting | **Forecasting** | Not available in Bookingsmaster |
| Sales planning, quota | **Forecasting** | Target data not in Bookingsmaster |
