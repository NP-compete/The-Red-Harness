### Strategic Issue Types

| Issue Type | ID | Description |
|------------|-----|-------------|
| Outcome | 10130 | Organizational objective focused on measurable outcome |
| Initiative | 10103 | Large product/portfolio goal with clear completion criteria |
| Epic | 10000 | Big user story that needs to be broken down |
| Story | 10009 | User story for development |
| Task | 10014 | Small unit of work, not end-user facing |
| Sub-task | 10015 | Sub-task of another issue |
